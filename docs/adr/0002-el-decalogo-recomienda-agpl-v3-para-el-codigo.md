# 2. El decálogo recomienda AGPL v3 para el código

Fecha: 2026-09-23 · Estado: aceptado

## Contexto

La versión 2.0 recomendaba GPL v3 para el software educativo, en los puntos 2
(participación activa), 5 (sostenibilidad) y 9 (licencias abiertas), y hablaba
de un archivo `LICENSE.txt` en el punto 10. El artículo del autor [«Licencias
libres para docentes»](https://educacion.bilateria.org/licencias-libres-para-docentes-apps-educativas-y-materiales-didacticos/)
y la [Guía para publicar materiales educativos creados con vibe coding](https://vibe-coding-educativo.github.io/vibe-responsable/),
que cita el decálogo como marco de principios, recomiendan AGPL v3 y un archivo
`LICENSE`.

## Decisión

Desde la versión 2.1, el decálogo recomienda AGPL v3 en los tres puntos, con las
mismas alternativas (MPL 2.0, Apache 2.0, MIT), y habla de un archivo `LICENSE`.
El cambio se aplica en todos los idiomas.

## Alternativas descartadas

- **Mantener GPL v3**: la mayoría de las aplicaciones educativas se ofrecen como
  páginas web, y la AGPL mantiene la reciprocidad también cuando el programa se
  usa a través de la red. Además, dejaba el decálogo en contradicción con la
  guía que lo cita.

## Consecuencias

El decálogo, la guía y el artículo de licencias recomiendan lo mismo. Un cambio
futuro en esa recomendación debe hacerse en los tres.

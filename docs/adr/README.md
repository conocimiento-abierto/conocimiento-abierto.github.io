# Registro de decisiones (ADR)

Cada archivo recoge una decisión que condiciona el trabajo futuro: su contexto,
las alternativas descartadas y sus consecuencias.

| Nº | Decisión | Estado |
|---|---|---|
| [1](0001-el-sitio-es-estatico-y-carga-las-traducciones-desde-json.md) | El sitio es estático y carga las traducciones desde archivos JSON | aceptado |
| [2](0002-el-decalogo-recomienda-agpl-v3-para-el-codigo.md) | El decálogo recomienda AGPL v3 para el código | aceptado |

Para añadir una, se copia [la plantilla](0000-plantilla.md) con el número
siguiente y se anota aquí. Una decisión que deje de valer no se borra: se marca
como «sustituida por» la nueva, para que quede el rastro.
